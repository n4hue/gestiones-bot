# Gestiones BOT - Tracker

Aplicación web para seguimiento de gestiones diarias como Analista BackOffice Técnico. 
Permite registrar interacciones, guardar estadísticas diarias, visualizar un historial y realizar copias de las gestiones.

## Características

- Registro rápido de gestiones con diferentes categorías.
- Herramientas de copiado para MACs y líneas telefónicas.
- Historial de gestiones y estadísticas de la sesión (gestiones por hora, rachas, categorías principales).
- Funcionalidad para exportar los datos.
- Modo oscuro y temas personalizables.
